# Little Lights Academy - Computer Science
The Little Lights Academy CS curriculum and documentation.

## How to Use this Repo
This repo is designed to contain and hold all parts of the LLA-CS curriculum - including the documents, scripts, and other tools needed for the class to be successful.

Homework assignments will be found under **/homework**
Projects, their rubrics and requirements will be found under **/projects**
Books and other resources will be found under **/resources**

## Start Here
Before your first class, set up your machine by following
**[/resources/setup/README.md](resources/setup/README.md)**. It installs the Java
toolchain and IntelliJ IDEA, then walks you through writing your first Java program by
hand.

## How this class will work
Unlike a normal class, while I will be giving a letter grade on in-class assessments and tests, they will be much more for your guidance on what concepts you got wrong, rather then *just* a grade. In real software development, while it is important to understand and get code as correct as possible, it will not be assumed that you got the answer right the first time. For homework and projects (especially the projects) you will be given a chance to go over and review your code and make any changes you deem necessary (not all comments made by me are valid, defend your code design!) and resubmit. I will regrade it accordingly to the updated result.

The goal of this CS class is mastery rather then just a passing grade. Good coding habits and hygiene start here, rather then out in the world doing a desk job where tradition and laziness prevail.
